# FayGer

[![Docs CI](https://github.com/ChainMode/FayGer/actions/workflows/docs-ci.yml/badge.svg)](https://github.com/ChainMode/FayGer/actions/workflows/docs-ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

[![Website: ifay.ai](https://img.shields.io/badge/Website-ifay.ai-blue)](https://ifay.ai)

**FayGer** is the portable virtual runtime environment for **Fay** autonomous avatars (`iFay` personal avatars anchored to a **Human Prime** and `coFay` public-role collaborative avatars) across desktop, mobile, embedded **Host** devices, and in-app containers. It provides deterministic execution sandboxing, capability adapter bridges, and lifecycle isolation so avatars run consistently across heterogeneous operating systems.
