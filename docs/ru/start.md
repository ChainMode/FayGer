# Быстрый старт Fayger

**Fayger** — это кроссплатформенная виртуальная среда выполнения (Virtual Runtime Environment) для Fay (`iFay` и `coFay`). Она принимает переносимые артефакты **BuF (Built-up Fay)** и декларативные манифесты сборки **FayManifest**, обеспечивая криптографическую проверку, управление жизненным циклом и изолированную адаптацию к хост-платформам (настольным системам, серверам, браузерам и встраиваемым устройствам).

> Терминологическое правило: **Хост (Host)** означает исключительно терминальное устройство или прикладной процесс; физическое лицо всегда именуется **Human Prime**.

## Трёхуровневая архитектура

1. **Уровень загрузки (Loader Layer)**: разбирает пятисегментные пакеты `BuF`, проверяет контрольные суммы, подписи Ed25519 и совместимость версий.
2. **Уровень выполнения (Runtime Layer)**: реализует языково-независимый контракт `Runtime_Interface` и квоты ресурсов, верифицируемые набором тестов `fayger-conformance`.
3. **Уровень адаптеров (Adapter Layer)**: преобразует команды `Universal_Instruction` при строгом соблюдении мандатов CAP и двухконтурной проверки подписи `Ego_Package`.

```bash
fayger version
fayger conformance
fayger demo live-ifay
```
